## Что сделать
1. Расширить `Board.ApplyMove(Move)`:

   - Если у своей группы 0 дамэ и не снято ни одного камня противника — `DomainException` с сообщением «Самоубийственный ход».
2. Добавить `Board.IsLegal(Move) → Result<Unit>` — без исключений, для AI.
3. Добавить `MoveResult` — `record struct MoveResult(bool IsLegal, Move Move, IReadOnlyList<Point> Captured, string? Reason)`.
4. Все тесты — через `Result`, не через `Exception`.
