# 07. Решения и история проекта

## Зачем это читать

`DECISIONS.md` — 114+ решений объёмом ~470 КБ. Это не книга для чтения подряд, а архив
«почему сделано именно так». Читайте по ссылке из нужного места или поиском по `D-0xx`.

## Формат решения

```
## D-0NN. Краткое название
Дата, статус, причина, что сделано, альтернативы, последствия (регрессия/проверка).
```

Свежие решения — в конце файла (нумерация возрастает). Ссылки на решения в коде и тестах —
в комментариях («D-070»), это нормальный способ передать контекст.

## Где что искать

| Вопрос | Файл |
|---|---|
| почему такая архитектура/решение | `DECISIONS.md` (`D-xxx`) |
| что требуется и в каком статусе | `REQUIREMENTS.md` |
| что было в работе и чем закончилось | `docs/10-implementation-log.md`; `STATE.md` (локальный снимок) |
| задачи и их отчёты | `TASKS/T-0NN-*.md`, `REPORTS/` |
| правила кода | `AGENTS.md` |
| границы проекта и стек | `PROJECT.md` |
| правила го | `GO_RULES.md` |

Если нужного решения нет — сначала проверьте `GO_RULES.md` и `samples/`, затем спросите;
не догадывайтесь (правило `AGENTS.md`, п. 13).

## Как добавить решение

1. Номер — следующий по порядку.
2. Название — что решили, а не «исправление бага».
3. Обязательно: причина, что сделано, чем проверено, что отбросили и почему.
4. Ссылки из кода/тестов/задачи — на `D-xxx`.
