## Проект в одном абзаце

Go Engine — офлайн-приложение для игры в го (9×9, 13×13, 19×19) и обучения: игра против ИИ,
36 задач, 12 уроков, 8 учебных партий-разборов, словарь терминов. Написано на C# 12 / .NET 8
с Avalonia UI 11 и SkiaSharp; собирается под Windows, Linux, macOS и Android (APK),
выпускается через GitHub Actions. Содержание (задачи, уроки, партии) хранится файлами в репозитории
и проверяется тестами.

## Словарь

| Термин | Значение |
|---|---|
| `Core` | слой правил и структур: доска, группы, ходы, ко, счёт. Без UI и IO |
| `AI` | выбор хода: MCTS, эвристики, уровни сложности |
| `Problems` | содержание: задачи, уроки, разборы партий, словарь; без Avalonia |
| `App` | библиотека интерфейса: виды, модели представления, сервисы, рисование |
| голова | платформенная точка входа: `App.Desktop`, `App.Android` |
| `Enumeration` | замена `enum` для доменных типов (см. AGENTS.md) |
| партия-разбор | записанная партия с пояснениями и вопросами |
| задача `reference` | задача из источника: правильность линии проверена экспертно, а не движком |
| коми | компенсация белым за первый ход (обычно 5,5–6,5) |
| `D-0xx` | номер решения в `DECISIONS.md` |

## Главные договорённости, которые ломают новички

1. **Слой не ссылается на слой выше.** `Core` не знает про Avalonia, `Problems` не знает про UI.
2. **Никаких `DateTime.Now`, `new Random()` без seed, логов в `Core`/`AI`**, `enum` для доменных типов.
3. **Публичный API доски иммутабелен**, внутри — плоский массив; `Clone()`/`MakeMove()` — только для MCTS.
4. **Ожидаемые исходы — `Result`, а не исключения.** `DomainException` — только нарушение инварианта.
5. **Координаты:** подпись доски не содержит буквы `I`; строки нумеруются сверху вниз;
   SGF задач читается снизу вверх — переворот строк делает `ProblemSgf` (см. `02-go-domain.md`).
6. **Сборка и тесты — общий ресурс:** не запускать параллельно в одной рабочей копии.
7. **Живой интерфейс — один на машину:** блокировка `%TEMP%\goengine-ui.lock`, не убивать чужие процессы.
