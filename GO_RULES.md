# Go — правила игры (канон проекта)

> Этот файл — источник истины для движка, AI, UI и тестов.
> Любое расхождение кода с этим файлом — баг.
> При сжатии контекста агент обязан перечитать этот файл первым.

## 1. Доска

- Размеры: `19×19`, `13×13`, `9×9`. Другие размеры запрещены.
- Координаты: `(x, y)`, где `x ∈ [0, size)`, `y ∈ [0, size)`.
- `x` — столбец слева направо, `y` — строка сверху вниз.
- `record struct Point(byte X, byte Y)`.
- Внешний вид (для UI): координаты по системе «A1…T19», буквы `A…T` без `I`, цифры `1…19` снизу вверх. Это только отображение, не внутренняя модель.
- Пустая точка — `StoneColor.Empty`.

## 2. Камни и цвета

- `Enumeration StoneColor`:
  - `Black` — чёрные, ходят первыми.
  - `White` — белые, ходят вторыми.
  - `Empty` — пусто.
- `StoneColor.Opponent()` — возвращает противоположный цвет (не для `Empty`).

## 3. Ход

- Ход — поставить камень своего цвета на пустую точку.
- Ход невозможен, если:
  1. Точка занята.
  2. Ход — самоубийство (см. п. 5).
  3. Ход нарушает ко (см. п. 6).
- Ход `Pass` разрешён всегда.
- Ход `Resign` разрешён всегда; после него партия окончена.

## 4. Захват (снятие)

- **Группа** — максимальное множество камней одного цвета, соединённых по стороне (не по диагонали).
- **Дамэ** (liberty) — пустая точка, соседняя по стороне с камнем группы.
- Группа захвачена и снимается с доски, если после хода у неё **ноль дамэ**.
- После постановки камня сначала снимаются группы противника без дамэ, затем проверяется своя группа.

## 5. Самоубийство

- Ход запрещён, если после снятия групп противника **своя группа** остаётся без дамэ.
- Исключение: ход, который снимает последнее дамэ у группы противника, разрешён, даже если своя группа окажется без дамэ — но только если при этом снимается хотя бы один камень противника.

## 6. Ко

- Применяется **позиционное суперко** (positional superko): запрещено делать ход, после которого позиция на доске (без учёта истории ходов) совпадает с любой предыдущей позицией в этой партии.
- Простое ко (запрет на немедленный обратный захват одного камня) — частный случай суперко и отдельно не проверяется.
- Позиция для сравнения — только расположение камней; очерёдность хода и коми не учитываются.

## 7. Пас

- `Pass` — ход без постановки камня.
- Два последовательных паса завершают партию (см. п. 8).

## 8. Завершение партии

- Партия завершается:
  1. Два последовательных `Pass`.
  2. `Resign` одного из игроков.
  3. Достигнут лимит ходов (для AI-партий: `2 × size × size` на игрока).
- После двух пасов — переход к подсчёту очков.

## 9. Подсчёт (китайские правила)

Применяются **китайские правила** (area scoring). Это устраняет неоднозначности с сэки.

- Очки чёрных = (число чёрных камней на доске) + (число пустых точек, окружённых только чёрными).
- Очки белых = (число белых камней) + (число пустых точек, окружённых только белыми) + коми.
- Точка считается окружённой цветом `C`, если все пути от неё до края доски проходят только через точки цвета `C` (через пустые — нельзя, через камни противника — нельзя).
- Сэки при китайских правилах не требует специальной обработки: камни в сэки остаются на доске, нейтральные точки не считаются ни за кого.
- **Мёртвые камни не снимаются** — игроки должны согласиться, что партия окончена. Для AI-партий: после двух пасов считаем по факту расположения на доске.
- Победитель — у кого больше очков.
- Результат — `Result<Score>`.

## 10. Коми

- `19×19`: коми = `7.5` для белых.
- `13×13`: коми = `5.5` для белых.
- `9×9`: коми = `5.5` для белых.
- Формат: `record struct Komi(double Value)`.

## 11. Глоссарий (русский)

| Термин | Значение |
|---|---|
| Дамэ | Свободная точка рядом с камнем группы |
| Атари | Группа, у которой одна дамэ |
| Группа | Связные по стороне камни одного цвета |
| Ко | Позиция, где немедленный обратный захват запрещён |
| Суперко | Обобщение ко на всю историю партии |
| Сэки | Позиция, где обе группы живут без двух глаз |
| Пас | Пропуск хода |
| Коми | Компенсация белым за второй ход |
| Цумэго | Задача «жизнь или смерть» |
| Дзёсэки | Стандартная последовательность ходов в углу |

## 12. Что НЕ входит в эту версию

- Гандикап (форовые камни) — отложено.
- Японские правила (territory scoring) — не поддерживаются.
- Правила ING — не поддерживаются.
- Тайминг (бёёми, канадский баёми) — отложено.
- Правило «тройное ко» — покрыто позиционным суперко.

## 13. Тестовые позиции

Для проверки правил движок обязан пройти следующие позиции (см. `TASKS/T-002`):

1. **Одиночный захват.** Чёрный камень в углу, белый ставит второй камень — чёрный снимается.
2. **Группа из двух камней.** Аналогично, группа из двух снимается целиком.
3. **Самоубийство.** Белый ставит камень в точку с одной дамэ, где нет захвата чёрных — ход отклонён.
4. **Захват с самоубийством.** Ход снимает чёрную группу, при этом своя группа без дамэ — ход разрешён.
5. **Простое ко.** Классическая позиция ко, обратный захват запрещён на один ход.
6. **Суперко.** Позиция, где нарушение возможно только через два хода — запрет срабатывает.
7. **Сэки.** Классическая позиция сэки, при китайских правилах нейтральные точки не считаются.
8. **Подсчёт территории.** Пустая доска 9×9 после нескольких ходов — точный подсчёт.
