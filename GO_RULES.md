# Go — правила игры (канон проекта)

> Этот файл — источник истины для движка, AI, UI и тестов.
> Любое расхождение кода с этим файлом — баг.
> При сжатии контекста агент обязан перечитать этот файл первым.

## 1. Доска

- Размеры: `19×19`, `13×13`, `9×9`. Другие размеры запрещены.
- Координаты: `(x, y)`, где `x ∈ [0, size)`, `y ∈ [0, size)`.
- `x` — столбец слева направо, `y` — строка сверху вниз.
- `record struct Point(byte X, byte Y)`.
- Внешний вид (для UI): координаты по системе «A1…T19», буквы `A…T` без `I`, цифры `1…19` снизу вверх. Это только отображение, не внутренняя модель.
- Пустая точка — `StoneColor.Empty`.

## 2. Камни и цвета

- `Enumeration StoneColor`:
  - `Black` — чёрные, ходят первыми.
  - `White` — белые, ходят вторыми.
  - `Empty` — пусто.
- `StoneColor.Opponent()` — возвращает противоположный цвет (не для `Empty`).

## 3. Ход

- Ход — поставить камень своего цвета на пустую точку.
- Ход невозможен, если:
  1. Точка занята.
  2. Ход — самоубийство (см. п. 5).
  3. Ход нарушает ко (см. п. 6).
- Ход `Pass` разрешён всегда.
- Ход `Resign` разрешён всегда; после него партия окончена.

## 4. Захват (снятие)

- **Группа** — максимальное множество камней одного цвета, соединённых по стороне (не по диагонали).
- **Дамэ** (liberty) — пустая точка, соседняя по стороне с камнем группы.
- Группа захвачена и снимается с доски, если после хода у неё **ноль дамэ**.
- После постановки камня сначала снимаются группы противника без дамэ, затем проверяется своя группа.

## 5. Самоубийство

- Ход запрещён, если после снятия групп противника **своя группа** остаётся без дамэ.
- Исключение: ход, который снимает последнее дамэ у группы противника, разрешён, даже если своя группа окажется без дамэ — но только если при этом снимается хотя бы один камень противника.

## 6. Ко

- Применяется **позиционное суперко** (positional superko): запрещено делать ход, после которого позиция на доске (без учёта истории ходов) совпадает с любой предыдущей позицией в этой партии.
- Простое ко (запрет на немедленный обратный захват одного камня) — частный случай суперко и отдельно не проверяется.
- Позиция для сравнения — только расположение камней; очерёдность хода и коми не учитываются.

## 7. Пас

- `Pass` — ход без постановки камня.
- Два последовательных паса завершают партию (см. п. 8).

## 8. Завершение партии

- Партия завершается:
  1. Два последовательных `Pass`.
  2. `Resign` одного из игроков.
  3. Достигнут лимит ходов (для AI-партий: `2 × size × size` на игрока).
- После двух пасов партия переходит к **согласованию заключительной позиции** (Правила вида спорта
  «го», утв. приказом Минспорта РФ № 815 от 05.11.2020 с изм. № 451 от 31.05.2022, пп. 1.9–1.10):
  стороны решают, какие камни на доске мертвы. Мёртвые камни снимаются и добавляются к пленникам
  того цвета, который их снял; полученная позиция называется **заключительной**, и очки считаются
  только по ней.
- В приложении предложение о мёртвых камнях даёт движок (`Endgame.ProposeDead`), игрок его проверяет
  и может помечать группы как мёртвые и снимать пометки; подсчёт выполняется по подтверждённой позиции.

## 9. Подсчёт

Систему подсчёта задаёт регламент турнира (Правила, пп. 1.11–1.13). Приложение знает обе и по
умолчанию применяет **японскую**: она принята в большинстве турниров РФГ, а в федеральных турнирах
(Кубок России, Командный чемпионат России, Первенство России) регламенты прямо говорят «правила
подсчёта очков японские, коми 6,5».

**Японская (основная).** Очки = территория + пленные + коми белым.

- Территория — пустые точки, у которых вся граница связной пустой области состоит только из камней
  одного цвета, включая точки, освободившиеся из-под снятых мёртвых камней (п. 1.11).
- Пленные — камни соперника, снятые в ходе партии, и камни, снятые как мёртвые в заключительной
  позиции (пп. 1.10, 1.12). За каждого пленника — одно очко.
- Точки в сэки не считаются ни за кого (Приложение I к Кодексу го, п. 2.3.1: подсчёт идёт
  «исключая входящие в сэки»).

**Китайская (вторая величина, показывается рядом).** Очки = свои камни на доске + своя территория,
плюс коми белым; пленные не считаются, вместо них считаются камни на доске (п. 1.13).

- Разница систем — 0 или 1 очко и равна разнице числа выставленных сторонами камней
  (Приложение I, п. 3.3.3): ни одна из величин не прячется, обе видны игроку.
- Точка считается окружённой цветом `C`, если она пустая и вся граница её связной пустой
  области состоит только из камней `C`. Край доски границу завершает и является стеной для обеих
  сторон: иначе территории у края не существовало бы вовсе, что противоречит п. 13.8. Если на
  границе области есть камни обоих цветов, точки этой области нейтральны (дамэ).
- Сэки специальной обработки не требует: камни в сэки остаются на доске под японской системой и
  снимаются как мёртвые под китайской, а нейтральные точки не считаются ни за кого.
- **Мёртвые камни снимаются**: подсчёт идёт по заключительной позиции, а не по конечной.
- Победитель — у кого больше очков по применяемой системе.
- Результат — `Result<Score>`; разбор подсчёта — `FinalScore` (камни, территория, пленные,
  нейтральные точки, коми, обе величины очков).

## 10. Коми

- Размер коми задаёт регламент встречи (Правила, определение «Коми»; п. 1.14); в приложении его
  выбирает игрок.
- Значения по умолчанию: `19×19` — `7.5`, `13×13` — `5.5`, `9×9` — `5.5` для белых.
- В турнирах РФГ типично `6,5` при японском подсчёте; при игре с форой — `0,5`.
- Формат: `record struct Komi(double Value)`.

## 11. Глоссарий (русский)

| Термин | Значение |
|---|---|
| Дамэ | Свободная точка рядом с камнем группы |
| Атари | Группа, у которой одна дамэ |
| Группа | Связные по стороне камни одного цвета |
| Ко | Позиция, где немедленный обратный захват запрещён |
| Суперко | Обобщение ко на всю историю партии |
| Сэки | Позиция, где обе группы живут без двух глаз |
| Пас | Пропуск хода |
| Коми | Компенсация белым за второй ход |
| Пленные | Камни соперника, снятые в партии или как мёртвые при подсчёте |
| Заключительная позиция | Позиция после снятия согласованных мёртвых камней; по ней считают очки |
| Цумэго | Задача «жизнь или смерть» |
| Дзёсэки | Стандартная последовательность ходов в углу |

## 12. Что НЕ входит в эту версию

- Гандикап (форовые камни) — отложено.
- Японская система подсчёта — поддерживается и объявлена основной (см. п. 9).
- Правила ING — не поддерживаются.
- Тайминг (бёёми, канадский баёми) — отложено.
- Правило «тройное ко» — покрыто позиционным суперко.

## 13. Тестовые позиции

Для проверки правил движок обязан пройти следующие позиции (см. `TASKS/T-002`):

1. **Одиночный захват.** Чёрный камень в углу, белый ставит второй камень — чёрный снимается.
2. **Группа из двух камней.** Аналогично, группа из двух снимается целиком.
3. **Самоубийство.** Белый ставит камень в точку с одной дамэ, где нет захвата чёрных — ход отклонён.
4. **Захват с самоубийством.** Ход снимает чёрную группу, при этом своя группа без дамэ — ход разрешён.
5. **Простое ко.** Классическая позиция ко, обратный захват запрещён на один ход.
6. **Суперко.** Позиция, где нарушение возможно только через два хода — запрет срабатывает.
7. **Сэки.** Классическая позиция сэки, при китайских правилах нейтральные точки не считаются.
8. **Подсчёт территории.** Пустая доска 9×9 после нескольких ходов — точный подсчёт.
9. **Пленные в партии.** Чёрные снимают группу из трёх белых камней: под японским подсчётом эти три
   камня дают чёрным три очка, под китайским — не дают ничего сверх площади.
10. **Мёртвая группа в заключительной позиции.** Группа без двух глаз остаётся на доске после двух
   пасов, снимается при согласовании: её камни идут в пленные соперника, освободившиеся точки —
   в его территорию, и счёт совпадает со счётом по доске, где группа была снята до подсчёта.
